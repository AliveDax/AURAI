# EmoArt data (not committed)

Download with `python scripts/download_emoart.py` (source: Hugging Face `printblue/EmoArt-130k`).

- License: **CC BY-NC 4.0**, non-commercial use only. Don't commit the images to the repo.
- Labels: 12 emotions, binary valence/arousal, descriptions, visual attributes and art-therapy
  effects, generated by GPT-4o with human verification. 5,600 images were human-validated.
- No physical dimensions. `scripts/enrich_dimensions.py` recovers sizes from The Met's API
  into `dimensions.csv` here; add others by hand (columns `art_id,height_cm,width_cm`).
